### Non-Critical Warnings:

## 1. OpenAI API Quota Exceeded ⚠️

**Error:**
```
Error code: 429 - insufficient_quota
Error building vector store: You exceeded your current quota
```

**Impact:** Vector store (FAISS) cannot build embeddings for semantic search

**Why It's OK:**
- Controls are still extracted and registered with the tracker
- Violations are being detected using direct control matching
- System falls back to mock controls when needed

**To Fix (Optional):**
1. Add OpenAI API credits to your account
2. Or use a different embedding provider (e.g., HuggingFace)
3. Or disable vector store and use direct matching only

**Workaround:**
The system automatically falls back to mock controls and continues working without vector store.

---

## 2. Ollama Connection Refused ⚠️

**Error:**
```
Error generating evidence with Ollama: [Errno 111] Connection refused
```

**Impact:** Cannot generate detailed evidence reports using local LLM

**Why It's OK:**
- Evidence generation is optional
- Violations are still detected and tracked
- Remediation suggestions are still generated by AI agents

**To Fix:**
```bash
# Start Ollama service
docker-compose up ollama -d

# Or if Ollama is not needed, ignore this error
```

**Workaround:**
The system continues without evidence generation. This is a non-critical feature.

---

## 3. PDF Encryption Warning ⚠️

**Error:**
```
PyPDF2 extraction failed: PyCryptodome is required for AES algorithm
```

**Impact:** Cannot extract text from encrypted PDFs using PyPDF2

**Why It's OK:**
- System falls back to OpenAI for PDF extraction
- Mock controls are used when extraction fails
- Controls are still registered and working

**To Fix:**
Add to `backend/requirements.txt`:
```
pycryptodome>=3.19.0
```

Then rebuild:
```bash
docker-compose build backend
docker-compose up -d
```

**Workaround:**
Use unencrypted PDFs or let the system use mock controls.
